# Requirements

## Functional requirements (what the system must DO)
1. The system shall let students submit free-text comments for a selected lecturer and course without revealing their identity
2. The system shall identify which predefined teaching aspecs each comment mentions.
3. The system shall categorise the comment into 3 sentiments towards lecturers (positive, negative, neutral)
4. The system will generate a short and concise summary of strengths and potential improvements for each lecturer.

## Non-functional requirements (how the system must PERFORM)
1. The system should analyse the feedback in real time and give out a summary in a few seconds.
2. The system shall have a clear and easy user interface so that users will be able to navigate through the system with ease.
3. The system should work with common browsers such as google chrome or safari.
